🚀 Deploy / Publish Site

To put this site online for free using GitHub Pages:

  1. Create a free account at github.com
  2. Create a new repository named blanson-post
  3. Upload all the site files (drag & drop in GitHub UI)
  4. Go to Settings → Pages → set source to main branch
  5. Your site will be live at yourusername.github.io/blanson-post

Articles added here are saved in the browser. To make them permanent, see the export option below.
